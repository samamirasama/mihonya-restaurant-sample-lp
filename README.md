# 地域の台所 みほん屋（飲食店ホームページ・ポートフォリオ用サンプル）

> **このページはポートフォリオ用の架空のサンプルです。** 店名「みほん屋」・住所（架空県みほん市れいだい町1-2-3）・電話番号（000-0000-0000）・メニュー・価格はすべて架空で、実在の店舗とは関係ありません。

## 何を見せるサンプルか
地域の小さな飲食店が「メニューを見て、営業時間と場所を確かめて、予約する」までを1ページで完結できるホームページです。

| セクション | 内容 |
|---|---|
| メインビジュアル | 定食の写真を画面いっぱいに見せ、キャッチコピーと「席を予約する」「お品書きを見る」ボタンを重ねる |
| 営業情報バー | 昼・夜の営業時間、定休日、電話番号をファーストビューの直下にまとめる |
| こだわり | 写真つきで3つ（土鍋ごはん・地元野菜・入りやすい店内） |
| お品書き | 「昼の定食／夜の一品／お飲みもの」のタブ切り替え。定食は写真カード、一品・飲み物は価格表 |
| 営業時間・アクセス | 営業時間の表、住所・電車・お車。地図は埋め込まず、Googleマップを入れる場所をプレースホルダーで示す |
| ご予約・お問い合わせ | 電話番号（タップで発信）と予約フォーム。必須チェック・定休日（水曜）の日付チェックつき。**送信先はなく、送信すると「サンプルのため送信されていません」と表示** |
| スマホ用固定ボタン | 画面下に「電話する」「Webで予約」を常に表示 |

## 写真について
外部の画像ファイルは使っていません。料理・店内の「写真」は **CSS（グラデーションと図形）で描いたイメージ** で、画面には「※写真はイメージです」と表示しています。実際の制作では、お店で撮影した写真（またはお店が権利を持つ写真）に差し替えます。

## 技術
- HTML / CSS / JavaScript（外部ライブラリなし）。ビルド不要
- レスポンシブ（スマホ 375px／タブレット 768px／PC 1280px で確認）。メディアクエリは `min-width` のモバイルファースト
- 外部の読み込みは Google Fonts（Noto Sans JP / Noto Serif JP、SIL Open Font License）のみ。読めない場合はシステムフォントで表示
- アクセシビリティ: 見出し階層（h1 は1つ）、本文へスキップ、ハンバーガーメニューの `aria-expanded` と Esc で閉じる、タブは矢印キーで移動、フォームのエラーを `aria-invalid` と `aria-describedby` で読み上げ、`prefers-reduced-motion` で動きを止める
- 検索エンジンに載らないよう `noindex, nofollow` を設定
